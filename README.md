# Prince Pangilinan | Personal Portfolio

A responsive Angular portfolio website using a forest-green, beige, and cream color palette.

## Run locally

1. Install Node.js (use a version supported by the Angular version in `package.json`).
2. Open this project folder in Terminal.
3. Run `npm install`.
4. Run `npm start`.
5. Open the local address shown by Angular, usually `http://localhost:4200`.

## Local images

All website artwork is stored locally in `public/images/` as PNG files. The site does not rely on external image URLs.

## Customize

- Edit your profile text and project details in `src/app/app.ts`.
- Edit page content in `src/app/app.html`.
- Edit component styling in `src/app/app.css` and global colors in `src/styles.css`.
- Replace or add PNG files in `public/images/` and update the corresponding image paths in `src/app/app.ts` or `src/app/app.html`.
